Limite di potenza

Trovi questo valore sul contatore o sull'interruttore generale (salvavita). In Italia i contratti domestici più comuni sono 3 kW o 4,5 kW; i salvavita riportano spesso l'amperaggio (es. 16 A).

Elettrodomestici

Attiva l'interruttore per gli apparecchi accesi in questo momento. La potenza reale è indicata sulla targhetta dell'apparecchio.

Dati e backup

I dati restano salvati automaticamente sul dispositivo (funziona anche offline). Usa "Esporta" per fare un backup, spostare i dati su un altro telefono, o versionarli nel repository GitHub.

Sincronizzazione GitHub

Configura il repository e un token con permessi su contents per usare GitHub come archivio condiviso tra PC e telefono.

Al login nel gruppo questi campi si compilano da soli con l'archivio condiviso predefinito: ogni dispositivo vede subito ciò che gli altri hanno inserito, senza bisogno di configurare nulla. Il token invece è personale: se vuoi solo vedere gli aggiornamenti degli altri non serve; se vuoi anche salvare le tue modifiche (accendere/spegnere elettrodomestici in modo che gli altri lo vedano) incollalo una volta per dispositivo — resta solo nel browser locale, mai condiviso altrove. Usa un token fine-grained limitato al solo repository del progetto.
